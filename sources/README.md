# Sources

Source material archived with the project so the log can be checked without a network: text editions of the witnesses, concordance data, scroll transcriptions, and any other reference the log cites.

Each item gets a line here when it is added: file or folder name, what it is, where it came from, its licence. Only material that may be redistributed is kept in the repository; a reference that cannot be redistributed is listed here with its citation and left out of the files.
