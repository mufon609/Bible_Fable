# Sources

Every witness, version and reference the log cites, with the edition behind it and where it was consulted. Rule 9 in CLAUDE.md: every reading names its source, and a source is entered here the first time it is used. The register is the scope list (CLAUDE.md, Scope): only the admitted texts are entered, and a text not in it is not cited. Within each witness the critical edition is the copy of record and is named; a manuscript image is cited only for a scroll covering the verse. Rows marked "reference, not a witness" hold material kept for checking and are not cited as a tradition. Versions are compared in the printing that was read, with the original printing noted where it differs; obscure versions and the newest revisions are not sought out.

Archived texts live in the folders below; each folder holds a `PROVENANCE.md` with the URLs fetched, the fetch date, the licence statement seen, and the sha256 of every file. Files named `*.derived.txt` are plain-text rearrangements made here from the archived data. Only material whose licence permits redistribution is archived; two folders (the Samaritan Pentateuch dataset and the Peshitta) are CC BY-NC 4.0 and would have to be removed if the repository were ever used commercially. Copyrighted editions and modern versions are cited by edition and quoted only in the short phrase a comparison needs.
